# Credits

Flight Deck is MIT. This file holds the notice of each piece of other people's work that Flight Deck forks, with the commit it took.

## Skills

Flight Deck's flows follow these skills. Each fork opens with a comment that names its upstream path, its commit, and what changed. Flight Deck bundles no unchanged copy of anyone's skill. A slot that names another skill, such as `tdd`, reads the one installed on the maintainer's machine.
